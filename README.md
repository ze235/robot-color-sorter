# 颜色分拣机器人任务模拟器

这是我的 Python 入门学习项目，使用 Tkinter 制作图形界面，
模拟物体从入口移动到对应箱子的过程。

## 项目功能

- 点击按钮添加红色、蓝色、黄色物体。
- 将物体分别送入 A、B、C 箱。
- 使用动画展示物体移动。
- 显示各箱数量和累计成功分拣数量。
- 箱子装满时停止接收对应颜色的物体。
- 支持清空箱子，保留累计分拣数量。

## 如何运行

1. 将项目下载到电脑并解压。
2. 用 Thonny 打开 sorting_window.py。
3. 点击运行按钮。
4. 在弹出的窗口中点击颜色按钮进行分拣。

运行环境：Python 3，需要支持 Tkinter。

## 程序流程

等待点击 → 检查箱子容量 → 判断目标箱子
→ 执行移动动画 → 更新数量 → 等待下一次操作。

### 项目版本变化

项目从文字交互版逐步扩展为图形界面版：

| 方面 | 文字交互版 | 图形界面版 |
|---|---|---|
| 操作方式 | 用键盘输入颜色 | 点击颜色按钮 |
| 任务展示 | 输出分拣过程文字 | 显示状态提示和物体移动动画 |
| 数量展示 | 通过文字查看统计 | 在界面中显示各箱数量及累计数量 |
| 容量管理 | 判断箱子是否装满 | 保留容量判断，并在窗口中提示 |
| 操作控制 | 按顺序接收输入 | 动画期间禁用按钮，避免任务相互干扰 |

以上功能由 AI 辅助提供实现方案和初始代码。
我正在通过运行、阅读、修改和测试，理解程序的工作过程。


### 个人修改：调整分拣动画速度

- 修改原因：希望演示时更容易观察物体的移动过程。
- 修改内容：将 move_item 函数中的动画刷新间隔从 30 毫秒改为 60 毫秒。
- 原理理解：每次移动的距离和总步数保持不变，增大两次移动之间的间隔，会让动画变慢。
- 验证操作：分别添加红色、蓝色和黄色物体，观察移动过程和完成后的计数。
- 实际结果：根据实际测试填写。
- 学到的知识：理解了 after() 的定时回调作用，以及刷新间隔对动画速度的影响。
